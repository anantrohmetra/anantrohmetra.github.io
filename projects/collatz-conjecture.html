Collatz Conjecture

The compositions implement the collatz conjecture algorithm. It is a famous, unsolved math problem stating that you can start with any positive integer and always eventually reach the number 1 by following two simple rules:

The Rules

  1. If the number is even, divide it by 2 (n / 2).
  2. If the number is odd, multiply it by 3 and add 1 (3n + 1).

The camera feed of the computer is connected to a filter where the amount of movement is mapped to a filter.
